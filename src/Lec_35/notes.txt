Tree is a non-linear data structure in Java DSA.
A Tree is a hierarchical data structure consisting of nodes connected by edges. It represents 
data in a parent-child relationship.
Why is a Tree non-linear?
A tree is called non-linear because:
Data is not arranged sequentially in a single line.
One node can connect to multiple child nodes.
Data follows a hierarchical structure.
Traversal can follow different paths.

Linear vs. Non-linear data structures
Linear:
Array
Linked List
Stack
Queue

Non-linear:
Tree
Graph


Types of Trees in Java DSA
Binary Tree: Each node has at most two children.
Binary Search Tree (BST): Left subtree values are smaller and right subtree values 
are larger than the node, under the usual distinct-key convention.
AVL Tree: A self-balancing binary search tree.
Heap: A tree-based structure used in priority queues.
